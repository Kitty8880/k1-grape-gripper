|---|---|
| 3M 纳米胶带 | 传感器固定不住，力传递失效 |
| 尼龙扎带 | 传感器会移位，标定失效 |
| **第二个 PS01** | **不满足比赛"双传感器"要求** |
| CH340 ×2 | 第二个传感器接不上 |
| 硅胶垫 | 葡萄容易破皮（核心指标） |
| **万用表** | **每次排查都要靠猜，效率极低** |
| 钢直尺 | 无法量开口、无法算垫块厚度 |
| PCA9685 | 舵机抖动影响力闭环稳定性 |
| 亚克力板 | 无法做对称垫块，葡萄会偏心 |
| M3 螺丝 | 结构件装不起来 |

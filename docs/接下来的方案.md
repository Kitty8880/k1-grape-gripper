### 任务 1.2 力策略表

**做什么**

在 `config.yaml` 里加：

```yaml
grasp_policy:
  grape:    {target_force_n: 0.4, force_max_n: 0.9,  approach_pulse: 790}
  egg:      {target_force_n: 1.5, force_max_n: 6.0,  approach_pulse: 850}
  pingpong: {target_force_n: 0.2, force_max_n: 2.0,  approach_pulse: 900}
  unknown:  {target_force_n: 0.2, force_max_n: 0.6,  approach_pulse: 900}
```

**验收标准**

```bash
python3 apps/object_classify.py --show-policy
# 打印出四类的参数表
```

### 任务 1.3 抓取验证状态机

**做什么**

```
apps/grasp_with_verify.py

  状态机：
    CLOSE     闭合到力策略里的目标力
    VERIFY    保持 3 秒，监测力是否稳定
    PROMPT    提示"请提起物体" → 用户按回车
    RECHECK   再测 3 秒
    DECIDE    判据：
                力稳定（变化 < 0.4N）    → ✅ 成功
                力下降 > 0.4N           → ⚠️ 加力 20% 重试（最多 2 次）
                仍下降                  → ❌ 放弃，报告原因
    RELEASE   松开
```

**验收标准**

```bash
python3 apps/grasp_with_verify.py --object grape --dry-run
# 打印完整状态流转，不驱动硬件
```

### 任务 3.2 完整流程验证

**跑通这条链路：**

```
说"请帮我夹一个葡萄"
   ↓ ASR 识别（3.2s）
   ↓ 意图判断
   ↓ 摄像头拍一帧
   ↓ HSV 找葡萄位置
   ↓ 分类模型确认"这是葡萄"（置信度 > 0.7）
   ↓ 查力策略表 → 目标力 0.4N
   ↓ 位置快速预闭合到 790µs
   ↓ 力闭环微调到 0.4N
   ↓ 提示提起 → 判力 → 成功
   ↓ 松开
```

**验收标准：连续 5 次成功，记录每次的耗时和力值**

### 任务 3.3 优化抓取速度

**目标：从 20 秒压到 8 秒以内**

| 优化 | 效果 |
|---|---|
| 位置快速预闭合（1450 → 820µs 用纯位置控制） | -8s |
| 远距窗口 0.25s → 0.15s | -2s |
| 力闭环窗口 2.0s → 1.2s | -3s |

**验收标准：完整抓取 < 10 秒**
